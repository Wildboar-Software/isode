# paradise/others/quipu/uips/idm — Interactive Directory Manager

Curses DUA for remotely managing organisation Directory accounts
(add/modify/delete people, OUs, and related entries) over DAP. Introduced in
PARADISE package release 2.

`idm` is built from `dm.c` plus per-object-class files (`people.c`, `org.c`,
`ou.c`, `country.c`, …). See `isode-paradise.pdf` Chapter 4.
