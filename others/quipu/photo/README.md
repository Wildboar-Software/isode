# others/quipu/photo — Photograph attributes

Renderers for the Quipu `photo` (and JPEG) attribute syntax: G3 fax bitmaps stored in the Directory. Edit `DISPLAY` in the Makefile to choose `ttyphoto`, `Xphoto`, `xfax`, `fax2ps`, `hexphoto`, `t4014`, `sunphoto`, and/or `jpegphoto`.

Point `dsaptailor` at the helper, e.g. `photo falco ttyphoto`. Test with the sample bitmap `sk`. Installs fax tables under `g3fax/`. See `READ-ME`.
