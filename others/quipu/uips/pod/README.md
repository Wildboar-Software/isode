# others/quipu/uips/pod — POpup Directory (X11 DUA)

Novice-oriented X11 DUA (X11R4, Xt, Athena widgets). Read, list, and most modify
operations; no add entry and no RDN change. Config files: `.podrc`, `readTypes`,
`friendlyNames`, `filterTypes`, `typeDefaults`.

Build `xpod`; `xrdb -merge Pod.ad` then `xpod -test` to use the source-tree
configs. User manual/guide: `pod.man.ps`, `pod.guide.ps`. Volume 5 chapter 8.
See `READ-ME`.
