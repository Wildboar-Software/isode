# others/quipu/uips/fred — FRED White Pages DUA

Whois-style Directory client for the NYSERNet White Pages pilot. Also installed as `in.whitepages` for TELNET/WHOIS access. `fredrc` / `ufnrc` are configuration; `fredsh` and `dad` are related helpers.

User docs: `doc/user.pdf`, `doc/quick.pdf`, and Volume 5 chapter 7. Administrator setup (TELNET, WHOIS, mail) is `doc/administrator.pdf` §2.8.
