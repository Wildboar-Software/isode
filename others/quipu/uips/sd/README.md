# others/quipu/uips/sd — Screen Directory (curses DUA)

Full-screen curses DUA derived from the ISODE 5.0 “widget” interface. Build with
`./make`; test with `xsd -test`. `x29/` holds files for running SD as a
public-access service (X.29/PAD). Volume 5 chapter 5 (SID) is the related
family. Historic contact: `x500@brunel.ac.uk`.
