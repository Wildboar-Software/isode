# others/quipu/uips/doog — User-Friendly Naming DUA

Pre-beta implementation of Steve Kille's UFN proposal, using asynchronous
`libdsap`. Included as example async Directory code, not a finished product (no
help pages, limited status reporting).

Build `xdoog`; `./xdoog -test` reads `doogrc` from the current directory. Sample
`config.*` files can replace `doogrc`. `query/` holds the query engine. See
`README`.
