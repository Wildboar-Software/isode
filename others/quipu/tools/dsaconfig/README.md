# others/quipu/tools/dsaconfig — DSA configurator

`dsaconfig` / `usconfig` walk an administrator through naming a DSA, writing tailor files, and loading a skeleton DIT (`inst-pilot` copies `quipu/` example data into `ETCDIR`). This is the program the NYSERNet White Pages Administrator's Guide (`doc/administrator.pdf`) calls “the DSA configuration program”.
