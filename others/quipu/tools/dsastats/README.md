# others/quipu/tools/dsastats — DSA log summariser

Script that reads `quipu.log` and prints usage totals (local vs remote, operations, associations). Requires `stats` logging at `TRACE`/`NOTICE` in `quiputailor` (or the defaults). Edit `LOGFILE`, `TAILORFILE`, and `LOCALORGDN` in the Makefile before install. See `README` in this directory.
