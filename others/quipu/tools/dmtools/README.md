# others/quipu/tools/dmtools — Data Management tools

Bulk load/update of Directory entries over DAP, using a text bulk format
(`dmformat`). Preferred to stopping the DSA and editing EDB files when data
comes from external sources. See the local `README` and `doc/isode-8-update.pdf`
Appendix B for format, shortcomings, and the push toward doing all management
over DAP.
