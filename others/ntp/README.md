# others/ntp — NTP over ROS

Network Time Protocol mapped onto OSI remote operations (and UDP). Historic and described by its own `READ-ME` as “not in very good shape”; originally exercised on SunOS 3. Edit `ntp-config.h` and the Makefile, then `make`. `config.examples/` holds sample `ntpd` configs.

This is **not** a modern NTP implementation. Keep it for protocol-stack archaeology.
